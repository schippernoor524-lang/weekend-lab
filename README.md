# Rain Walk Log

A tiny weekend project for learning a mobile-first GitHub + Streamlit workflow.

## What this is
This app shows short notes and photos from a weekend of walks, food, tools, and experiments.

## Files
- `streamlit_app.py` — the app
- `content/notes.md` — the text content
- `assets/` — photos
- `requirements.txt` — Python dependencies

## Local run
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
